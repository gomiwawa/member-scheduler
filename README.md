# 나의 예약 스케줄러

회원의 하루 수업 예약을 날짜와 강의실별로 관리하는 간단한 웹앱입니다. 휴대폰 화면에서도 사용할 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 열거나 GitHub Pages에 올려 사이트를 엽니다.
2. 날짜를 선택하고 **예약 등록**을 눌러 회원 이름, 시간, 강의실을 입력한 뒤 저장합니다.
3. 예약을 누르면 내용을 수정하거나 삭제할 수 있습니다.

예약 정보는 현재 사용 중인 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서는 다시 열어도 남아 있지만, 다른 기기나 브라우저와 공유되지는 않습니다. 브라우저 데이터를 지우면 예약도 함께 지워집니다. 회원 이름과 비고에는 공개해도 되는 정보만 입력하세요.
